# mdchannel

Виджеты для Telegram-каналов и бот [@mdchannelbot](https://t.me/mdchannelbot) внутри них.

Виджет — это живое сообщение: опрос, игра, курс валют, промокод, карта лояльности. Он работает прямо в ленте
Telegram. В @mdchannelbot виджет можно взять из готовых шаблонов, а можно сделать свой: одна HTML-страница,
которую легко написать самому или попросить ИИ.

`mdchannel` — небольшая библиотека, через которую виджет получает то, чего у него нет без бота:

- **общие счётчики** — лайки, «иду», что угодно;
- **голоса и оценки** — по одному на человека;
- **данные бота** — курс ЦБ с историей для графика;
- **поля формы** — тексты, которые автор меняет в редакторе без кода.

```js
button.onclick = function () {
  mdchannel.count("likes").then(function (total) { label.textContent = "Уже " + total; });
};
```

Подключать ничего не нужно: пишите в коде `mdchannel.…`, бот сам добавит библиотеку, когда публикует виджет.

## Как это устроено

[`mdchannel.js`](mdchannel.js) — сама библиотека. Бот вставляет её в виджет перед его кодом и кладёт туда только
методы, которые виджет использует. Без бота (в превью, в пересланном сообщении) она считает всё у самого читателя,
так что виджет работает всегда.

Виджеты в Telegram — новая возможность Bot API 10.4 (бета). Документация Telegram:
[формат](https://github.com/TelegramMessenger/widget-sandbox/blob/main/docs/tgw-format.md),
[SDK](https://github.com/TelegramMessenger/widget-sandbox/blob/main/docs/sdk-v1.md).
